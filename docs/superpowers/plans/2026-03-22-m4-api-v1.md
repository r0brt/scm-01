# M4 API v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the first synchronous API v1 for creating, listing, reading, and rerunning analysis runs.

**Architecture:** Keep the API thin. Introduce request/response schemas and a minimal application service that uses a stubbed analysis generator, the existing validation layer, and the run repository. Persist every run through the M3 database layer and map failures to the PRD error contract.

**Tech Stack:** FastAPI, Pydantic v2, SQLAlchemy 2, pytest, httpx test client
