## Release Summary

- FastAPI-Backend mit Analyse-, Listen-, Detail- und Rerun-API ist vorhanden
- React/Vite-Frontend für Analyse-Flow und Archiv ist vorhanden
- Analyse-Contract, Prompt-Versionierung, lokale Sprachdetektion und Persistenz sind umgesetzt

### E2E-Status

```bash
cd frontend
npm run test:e2e
```

- Ergebnis: aktuell nicht grün in der Re-Onboarding-Umgebung
- Grund: fehlende lokal installierte Playwright-Browser-Binaries
- Positiver Befund: nach gestopptem Compose-Stack startete das lokale Frontend-/Backend-Setup korrekt

## Bekannte Limitationen

- Datenschutz, AI-Act-Einordnung und explizite Governance-Dokumentation sind noch nicht auf Bewertungszielniveau
- arc42 ist inhaltlich brauchbar, aber für das Ziel `25-30 Seiten inkl. Reflexion` noch zu knapp
- E2E benötigt für einen vollständigen Lauf lokal installierte Playwright-Browser
- der vorhandene E2E-Test bleibt ein schmaler UJ1-Nachweis

## Empfohlene Reihenfolge für den Freeze

1. Diese Vorbereitungs-Branch reviewen und nach `main` bringen
2. Vor einem finalen E2E-Nachweis sicherstellen, dass `npx playwright install` lokal ausgeführt wurde
3. Optional `npm run test:e2e` in sauberer Umgebung erneut laufen lassen
4. Auf `main` den annotierten Tag setzen
5. GitHub Release mit den unten stehenden Notizen anlegen
