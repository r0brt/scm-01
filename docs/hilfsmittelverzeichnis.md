# Anhang: Hilfsmittelverzeichnis

Die folgende Tabelle deklariert die im Projekt eingesetzten Hilfsmittel. Sie ergänzt die Reflexion zum KI-Einsatz und die Selbständigkeitserklärung.

| Hilfsmittel | Einsatz | Betroffene Stellen |
| --- | --- | --- |
| Codex mit Superpowers | Unterstützung bei Planung, Implementierung, Tests, Reviews, Git-/PR-Arbeit und Dokumentationspflege | Projektstruktur, Backend, Frontend, Tests, `docs/arc42/`, ADRs, Testreport, Abnahmecheckliste, PDF-Export |
| ChatGPT | Brainstorming, Formulierungsvarianten und Reflexionsfragen | Einzelne Review- und Formulierungsschritte, insbesondere Reflexion KI-Einsatz und Fazit |
| GitHub Actions | Automatisierte Ausführung der CI-Checks für Backend und Frontend | PR-Verifikation, Testnachweise und Abnahmecheckliste |
| Externer KI-gestützter Dokumentationsreview | Plausibilitäts- und Konsistenzreview der generierten PDF-Dokumentation | Finale Politur der arc42-Dokumentation, insbesondere Titelblatt, Diagrammhinweise, Deployment View und Layout |
| OpenAI API / LLM-Provider | Entwicklung und Prüfung der KI-gestützten Analysefunktion im Produkt | LLM-Adapter, Prompting, JSON-Contract, Validierung und Analyse-Metadaten |
